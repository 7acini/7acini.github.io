# Declaração para Dandara

Site estático em HTML, CSS e JavaScript, pronto para ser publicado gratuitamente no GitHub Pages.

## Adicionar as fotos

Adicione seis fotos na pasta `assets` com estes nomes:

- `foto-01.jpg`: foto principal de vocês
- `foto-02.jpg`: retrato da Dandara
- `foto-03.jpg` até `foto-06.jpg`: outras memórias especiais

As imagens podem ter qualquer tamanho, mas fotos verticais funcionam melhor. Sem esses arquivos, o site exibe composições românticas no lugar das fotos.

## Personalizar o texto

Abra `index.html` e altere livremente as declarações. Os principais textos estão nas seções `Sobre nós`, `Nosso álbum`, `Minha carta aberta` e `Mensagem final`.

## Publicar no GitHub Pages

1. Envie estes arquivos para um repositório no GitHub.
2. Abra `Settings` > `Pages` no repositório.
3. Em `Build and deployment`, escolha `Deploy from a branch`.
4. Selecione a branch `main`, a pasta `/ (root)` e clique em `Save`.
5. Aguarde alguns minutos. O endereço público aparecerá na mesma tela.

Não é necessário instalar dependências nem executar um processo de build.
